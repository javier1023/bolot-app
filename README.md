# Bolot - app web del juego de cartas de Sagunto

App web para jugar al bolot, el juego de cartas de Sagunto: contra la máquina, en salas online con otra gente y con anotador para partidas presenciales. Motor de juego propio en Python (FastAPI), frontend con Vite, baraja SVG generada por el propio proyecto y grabación de partidas reales para entrenar una IA (modelo en desarrollo).

App en producción: https://app-bolot.onrender.com

Copia pública de demostración: instantánea sin historial (noviembre de 2026), sin datos privados; el repositorio de desarrollo es privado. Proyecto personal desarrollado con IA generativa como herramienta principal de programación.
